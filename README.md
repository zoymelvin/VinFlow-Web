# VinFlow

VinFlow is a premium personal finance tracker app. Track expenses, manage budgets, and visualize your financial health.

## Tech Stack
- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Zustand (Persisted Stores)

## Getting Started

1. Clone the repository and install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Environment Variables
Create a `.env.local` file in the root directory based on `.env.example`:
```env
GEMINI_API_KEY=your_gemini_api_key_here
```

## Data Privacy
All personal financial data is stored securely in your browser's local storage. No server login required.
